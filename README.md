## 🔬 Architecture & Features

- **3D Silicon Monolith Intro**: Custom procedural 1024×1024 silicon micro-architecture wafer shader with audio-synthesized relativistic warp drive.
- **Interactive 3D ASIC Wafer Stack**: Multi-layer 3D semiconductor visualization showcasing Substrate, Transistor Diffusion, Metal 1-3 interconnects, vertical vias, and passivation pads.
- **3D 5-Stage RISC-V Pipeline Matrix**: Real-time simulation of Instruction Fetch (IF), Decode (ID), Execute (ALU), Memory (MEM), and Writeback (WB) with instruction packet traversal.
- **Continuous 2-Row Skills Marquee**: Independent hover-pausing tracks delivering immediate inspection of both hardware and software toolchains.
- **Biomedical EEG Oscilloscope**: Interactive canvas analyzing real-time brainwave frequencies from BCI research conducted at IIT Bhubaneswar.

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17+ or Node.js 20+
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Purush-5268/purushotham-portfolio.git
cd purushotham-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build

```bash
npm run build
npm run start
```
